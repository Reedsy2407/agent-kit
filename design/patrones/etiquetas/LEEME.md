# Etiquetas

Lista de palabras clave (tecnologías, temas) como `ul` con `li`: informativas, no interactivas.

- Texto de 15 px (`--t-note`) y contraste `--ink-soft` sobre la superficie (anotado en `styles.css`).
- El significado no depende del color: es texto con borde.
- Si alguna etiqueta pasa a ser enlace o botón, debe cumplir el objetivo táctil de 44 px.
